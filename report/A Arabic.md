2. التعارض (Merge Conflict)
ماذا ظهر لك؟ لتطبيق مهارة حل التعارضات المطلوبة عملياً بمفردي، قمت بإنشاء فرع محلي آخر (Branch) وأدخلت تعديلات مختلفة على ملف README.md بداخل نفس السطور. وعند محاولة الدمج، ظهرت لي علامات التعارض القياسية الخاصة بـ Git وهي:

<<<<<<< HEAD (التعديل الحالي)، و ======= (الفاصل)، و >>>>>>> (التعديل المراد دمجه).

ماذا قررت ولماذا؟ قررت دمج التعديلين يدوياً لإظهار الهيكلية الكاملة للمستودع وضمان وجود كافة التعليمات في التوثيق النهائي بدلاً من إلغاء أي جزء.

كيفية الحل: قمت بفتح الملف في محرر VS Code، ومسحت رموز التعارض (<<<<<<<, =======, >>>>>>>) يدوياً، ونسقت السطور لتصبح متكاملة، ثم حفظت الملف وقمت بعمل Commit دمج رسمية (Merge commit).

(📸 تنبيه: يرجى إرفاق لقطة شاشة لعلامات التعارض في VS Code هنا).

3. التراجع: الفرق بين الحالات الثلاث وتطبيقها
الفرق بين الحالات ومتى تُستخدم كل منها:

git checkout / Discard: تُستخدم للتراجع عن التغييرات المحلية غير المحفوظة بـ Commit في ملف معين بداخل مجلد العمل. تُستخدم أثناء تجربة كود مؤقت وتتيح العودة للنسخة المحفوظة بسهولة.

git reset: تُستخدم للتراجع عن Commit أو أكثر قمت بها محلياً ولكنك لم تقم برفعها على GitHub بعد (لم تنفذ Push)، وهي تقوم بتعديل سجل المستودع المحلي.

git revert: تُستخدم للتراجع عن Commit تم رفعها بالفعل على GitHub (Remote)؛ حيث تقوم بإنشاء Commit جديدة عكسية تعطل التأثير الخاطئ دون مسح تاريخ المستودع، وتعد الطريق الآمن والأنسب في بيئات العمل الحقيقية.

التطبيق العملي: قمت بافتعال خطأ برمجي عمداً في ملف public/index.php ورفعه بـ Commit على GitHub، ثم نفذت أمر git revert <commit-hash> لتوليد Commit عكسية ألغت الخطأ وأعادت الكود للعمل بنجاح دون مسح أي مرحلة من سجل المستودع.

(📸 تنبيه: يرجى إرفاق لقطة شاشة لسجل المستودع History في GitHub Desktop يظهر فيها الـ Revert هنا).

4. أصعب شيء واجهك في العمل الجماعي وكيف تجاوزته
التحدي: كان أصعب تحدٍ هو انسحاب وتراجع زملائي عن المادة واضطراري لتحمل كافة أجزاء المشروع (الواجهات الأمامية، الواجهات الخلفية، قاعدة البيانات، وتوثيق سجل الـ Commits في Git) بمفردي في وقت محدد.

كيفية التجاوز: قمت بتنظيم الوقت وتقسيم المشروع إلى مهام صغيرة متسلسلة، والالتزام بعمل Commits مستمرة برسائل إنجليزية واضحة، مع تطبيق PDO وتنسيقات Bootstrap لإنهاء المشروع بنجاح وضمان تلبية كافة الشروط المحددة.
